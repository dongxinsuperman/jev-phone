# README 官网源页面

这里保存 Demo 技术页的完整 HTML、原样式和图片引用。`layout.css` 只适配文档宽度、字号和纵向布局；`manual.en.html` 为同内容英文版。原始三端编号图从 `../media/` 引用。

导出方式：浏览器将完整页面按 1000 CSS px 宽、2倍像素密度整页渲染为 `website-guide.zh.png` 和 `website-guide.en.png`，不裁切模块。`demos.html` 将两张完整1920px宽Demo实录画面纵向排布，整页导出 `demo-views-hd.png`。

两段动画的采用条件独立保留：每一步完整耗时不超过1700ms。当前未达标动画不嵌入README。
