05 / INTEGRATION

Independent SDK integration

from jev_phone import AndroidClicker

with AndroidClicker(
    serial="YOUR_DEVICE_SERIAL",
    api_key=your_key,
    provider="openrouter",
) as phone:
    report = phone.run("Tap Star; tap My profile")
    print(report["results"])
    print(report["transitions"])

# Single tap: phone.click("Tap My profile")
# iOS: IOSClicker(wda_url, your_key)
# HarmonyOS: HarmonyClicker(hdc_serial, your_key)

Install: Android pip install -e '.[android]'，iOS pip install -e ., HarmonyOS pip install -e '.[harmony]'. Independent usage needs no webpage or database. Split by punctuation and newlines; stop on failure. Use on_event to receive capture, annotation, selection, and tap-completion events.

07 / PRACTICE NOTES

Current capabilities and future work

Runtime

Install Python dependencies, ADB, scrcpy, and ffmpeg, and connect an authorized Android phone. Enter the appropriate key in the Demo, prepare the model connection, then execute steps.

Model providers

Supports OpenRouter multimodal Decisions and official OpenAI Decisions. Adapters handle request and response differences and normalize the decision result.

Scope

Delivers single and sequential taps on physical devices and emulators across all three platforms. Text input, scrolling, and long press require further region, gesture, and platform work and are not shipped. Transitions use tuned V3 intervals: Android 100ms, HarmonyOS 0ms, iOS 200ms.

Evidence and credentials

Enter credentials in the current page, displayed as masked input. Refreshing clears the connection and key; keys are not restored or persisted. Screenshots and execution records are saved locally.
