# SDK 升级与维护

当前版本：**0.1.1（2026-10-13）**。支持从源码或 wheel 安装。

以下命令适用于macOS / Linux，以Python3.11为例。公开仓库克隆无需登录GitHub。

## 获取与安装

可以从公开仓库克隆并固定版本：

```sh
git clone https://github.com/dongxinsuperman/jev-phone.git
cd jev-phone
git checkout v0.1.1
python3.11 -m venv .venv
.venv/bin/python -m pip install -e '.[android]'
```

iOS 使用 `-e .`，鸿蒙使用 `-e '.[harmony]'`；Demo 使用 `-e '.[demo]'`。Python 要求 3.10+，Pillow 要求 10.1+。设备服务与模型 Key 由调用方自行配置。

交付包解压后，也可以安装包内 wheel，无需克隆仓库：

```sh
python3.11 -m venv .venv
.venv/bin/python -m pip install './wheel/jev_phone-0.1.1-py3-none-any.whl[android]'
```

## 从旧版升级

结束当前调用并停止自己启动的 Demo 进程，再更新代码和依赖。先用 `git status --short` 确认本地改动已提交或保存；不要覆盖自己的代码。

先进入已克隆仓库的根目录，沿用已有虚拟环境；没有虚拟环境时先执行`python3.11 -m venv .venv`。

```sh
git fetch origin --tags
git checkout v0.1.1
.venv/bin/python -m pip install -e '.[android]'
.venv/bin/python -c "from importlib.metadata import version; print(version('jev-phone'))"
```

升级 wheel 安装时，重新执行对应版本的 wheel 安装命令即可。安装完成后重启使用 SDK 的 Python 程序或 Demo，让进程加载新代码。已经运行的进程不会自动更新。编辑安装直接使用当前 checkout 的源码；wheel 安装使用环境中安装的版本。

0.1.1 已提供 [PyPI 安装](https://pypi.org/project/jev-phone/0.1.1/)：`python -m pip install --upgrade "jev-phone[android]==0.1.1"`。按平台替换 extras；升级后重启使用 SDK 的进程。

## 兼容与回退

0.1.1 与 0.1.0 的 Clicker 构造参数、`click`、`run`、事件及结果接口兼容。版本变更见 [CHANGELOG](../CHANGELOG.md)。

需要回退时，对源码安装执行 `git checkout v0.1.0` 后重新安装对应 extras；wheel 安装重新安装保存的旧版 wheel。随后重启调用程序。交付时保留上一版包，便于回退。

## 问题反馈

通过仓库 Issues 提交 SDK 版本、平台、复现步骤和脱敏后的错误日志，便于定位问题。

## 源码包、wheel与文档更新

完整交付包含源码、示例与文档；单独wheel只含SDK和Demo资源，不包含仓库中的`examples/`和README。运行仓库示例需要源码包，不能在任意目录执行不存在的脚本。

`v0.1.1`对应固定版本代码，最新文档在main分支维护。需要最新文档时在自己的main分支执行`git pull --ff-only`，或使用重新生成的交付包；升级SDK仍按明确版本tag操作。包内`manifest.json`记录对应提交与文件SHA-256，可用于核对包内容。
