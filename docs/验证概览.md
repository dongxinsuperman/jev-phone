# 验证概览

Android、iOS、HarmonyOS 真机与虚拟机的基本模型点击均已贯通。SDK 支持单步、多步、失败停止和跨设备并行；Demo 使用同一 SDK 执行流程。

| 平台 | 真机 | 虚拟机 | 设备服务 | 图片对比额外采样间隔 |
|---|---|---|---|---|
| Android | 已贯通 | 已贯通 | ADB / UiAutomator2 | 100ms |
| iOS | 已贯通 | 已贯通 | 已有 WDA | 200ms |
| HarmonyOS | 已贯通 | 已贯通 | HDC / UITest | 0ms |

通道采用 V3 已调实现。只在步骤之间做图片对比；下一步复用最后一帧，不追加每步结束后截图。0ms指没有额外sleep，截图本身仍耗时。

单步完成状态driver_completed表示驱动返回；业务判定由调用方完成。基本样本覆盖不代表所有设备系统版本或完整业务场景都已验证。

原始日志、个人设备标识、截图与密钥不随交付包分发。当前版本0.1.0为本地评审交付，尚未公开发布。
