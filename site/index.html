05 / INTEGRATION

独立组件接入

from getpass import getpass
from jev_phone import AndroidClicker

with AndroidClicker(
    serial="YOUR_DEVICE_SERIAL",
    api_key=getpass("OpenRouter Key: "),
    provider="openrouter",
) as phone:
    report = phone.run("点击星球；点击我的")
    print(report["results"])
    print(report["transitions"])

# 单步：phone.click("点击我的")
# iOS：IOSClicker(wda_url, your_key)
# 鸿蒙：HarmonyClicker(hdc_serial, your_key)

安装：安卓 pip install 'jev-phone[android]'，iOS pip install jev-phone，鸿蒙 pip install 'jev-phone[harmony]'。独立调用不需要 Web 页或数据库。支持按标点及换行拆步，失败停止；可通过 on_event 接收采集、编号图、选择和点击返回事件。

组件自身处理尺寸／树＋按需截图＋候选画框＋点击
单步总时间 = 两部分相加 单位 ms

模型时间采用请求往返口径，包含传输与服务处理。不逐步追加结束后截图；步骤间对比采样，下一步复用末帧。点击接口返回与业务判定分别记录。

客户端空闲连接有效期 180 秒。端到端耗时受网络、模型服务、页面与设备负载影响。

07 / PRACTICE NOTES

当前能力与后续探索

运行环境

SDK 使用 Python 3.10+，根据平台准备 ADB／UiAutomator2、WDA 或 HDC／UITest。官网无需安装或连接设备；本地安卓 Demo 的实时镜像另需 scrcpy 和 ffmpeg。

模型通道

支持 OpenRouter 多模态 Decisions 与 OpenAI 官方 Decisions，内部适配不同请求和返回协议。两种协议通过适配层归一化决策结果。

明确边界

当前交付单步与多步点击，三端真机／虚拟机均已贯通。输入、滚动、长按等更多动作需要分别探索区域选择、手势参数与平台承接，还没有作为本组件能力交付。步骤衔接沿用 V3 已调参数：安卓100ms、鸿蒙0ms、iOS200ms。

证据与密钥

模型 Key 由调用方提供给 SDK，官网不接收、不保存 Key，也不连接设备。这里展示已录制的真实画面和计时，实际执行记录由接入方管理。
